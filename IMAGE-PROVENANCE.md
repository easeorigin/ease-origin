# Image Provenance

Every image shipped in `public/images/`, with where it came from.

Why this file exists: the repository previously carried a provenance record
for 8 images while shipping 74. An image with no recorded source cannot be
cleared for use in a proposal, a capability statement, or any document that
leaves the company, because there is no way to answer the question of who owns it.

## Status

- **Unsplash (recorded)**: sourced from Unsplash. The Unsplash License grants use
  without permission and does not require attribution. Credit is courtesy only.
- **UNKNOWN, needs record**: no provenance recorded. Do not use outside the website
  until the source and license are confirmed. If the source cannot be established,
  replace the image rather than keep it.

## Rule going forward

Add a row here in the same commit that adds the image. An image without a row
does not ship.
